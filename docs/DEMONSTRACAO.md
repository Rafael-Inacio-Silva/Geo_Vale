# Roteiro de apresentação

Execute o projeto conforme o README. Os dados e imagens já foram obtidos; a jornada não precisa baixar rasters durante a apresentação.

1. Tenha os arquivos da pasta `~/Desktop/Mapas GeoVale/` no computador. Abra o site, clique em **Enviar GeoJSON** e selecione **Rapatee.geojson**. O mapa deve ser escolhido no computador para iniciar a análise.
2. Mostre o contorno, a imagem aérea e a área de aproximadamente **162,29 ha**. Esclareça que é um recorte público de operações de uma mina real dos EUA.
3. Clique **Analisar área**. O relevo e a cobertura 2024 são lidos de rasters reais; não há previsão por ML.
4. Explique os três pesos e compare com importância inicial igual. Opcionalmente, abra **Comparar prioridades** para mostrar AHP.
5. Clique **Comparar opções**. Mostre a prioridade de estudo, o índice relativo e a observação de pendências.
6. Clique **Salvar resultado** e baixe os dois relatórios. O simples apresenta a decisão exploratória; o técnico permite inspecionar cálculo, dados e hipóteses.
7. Use **Trocar mapa** e envie **Burning Star 3.geojson** da mesma pasta, aproximadamente **530,55 ha**.

Com os pacotes congelados e pesos neutros exibidos (33,34/33,33/33,33), o smoke de referência produziu:

| Caso | Agricultura | Uso florestal | Recreação aberta |
|---|---:|---:|---:|
| Rapatee | 0,974 | 0,719 | 0,013 |
| Burning Star 3 | 0,981 | 0,306 | 0,010 |

Ambos têm agricultura na primeira posição neste perfil. Isso não foi forçado para variar a apresentação. Os números não são acurácia, porcentagem de aptidão ou evidência de viabilidade. Também não se comparam entre minas como escala absoluta. Mudanças de hipóteses, fontes ou pesos exigem nova análise; a posição não é uma recomendação homologada.

Frase para a apresentação: “O GeoVale organiza informações geográficas e prioridades para comparar possibilidades de uso e indicar onde aprofundar os estudos. O método é rastreável; a escolha final depende de avaliações técnicas e dos envolvidos.”

Não apresentar como sistema validado para a Vale, análise de segurança, autorização ou prova de que agricultura seja o melhor destino real. As fotos são históricas e o limite representa operações registradas. Nenhum uso é autorizado por esta demonstração.
