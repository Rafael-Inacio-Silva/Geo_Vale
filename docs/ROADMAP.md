# Roadmap revisado

As etapas anteriores permanecem como histórico de construção, mas o planejamento ativo foi revisto para a rota sem ML. Não reaproveitar contagens antigas de testes como evidência desta versão.

| Etapa | Situação na nova rota |
|---|---|
| 0 — Preparação | Ambiente e Git existentes aproveitados; instruções locais continuam excluídas. |
| 1 — Negócio | Objetivo de apoio à comparação preservado; saída delimitada como prioridade de estudo. |
| 2 — Requisitos | Revisados para GIS + AHP + TOPSIS, sem login público ou previsão de uso. |
| 3 — Modelagem | Jornada única, estados e invalidação definidos/implementados. |
| 4 — Arquitetura | API + React locais na mesma origem; implantação remota deixa de ser condição da demonstração. |
| 5 — Banco | Revisões SQLite imutáveis e dois relatórios do mesmo retrato. |
| 6 — Dados | Rapatee e Burning Star 3 preparados com fontes reais e hashes. |
| 7 — Funcionalidades | Upload, mapa aéreo, análise, prioridades, comparação, salvamento e exportação implementados. |
| 8 — Métodos de decisão | Substitui a etapa ML: AHP, TOPSIS e sensibilidade implementados e testados. |
| 9 — Validação de software | Testes matemáticos, validação de entrada, jornada HTTP, build e inspeção da interface. Ver VALIDACAO.md. |
| 10 — Entrega local/documentação | Código, testes, dados de referência e documentação revisados para versionamento no GitHub. Linux, implantação e segurança corporativa não executados. |
| 11 — Apresentação | Dois casos e roteiro disponíveis; ensaio pelo responsável e validação especializada ainda necessários. |

A demonstração do software não encerra a validação científica/operacional. Próximos trabalhos: parecer especializado sobre critérios e notas; novos dados de restrição e custo; fontes brasileiras; autenticação/infraestrutura antes de qualquer acesso externo; testes no ambiente de implantação escolhido.
